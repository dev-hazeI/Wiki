Installation

Installation

General instructions for installing Minecraft plugins.

1. Download the plugin

Download the plugin's compiled JAR file from its GitHub release or build output.

2. Open your server directory

Find the plugins folder inside your Minecraft server.

3. Place the plugin inside plugins 

server/
└── plugins/
    └── MyPlugin.jar

4. Restart the server

Restart the Minecraft server and check the console for errors or dependency issues.

Important

Always check the project's documentation for its required Minecraft version, dependencies, and supported server software.

Development

Plugin Development

Building Minecraft plugins with Java, Paper, Bukkit, and related APIs.

Main class

A basic Bukkit or Paper plugin starts with a class extending JavaPlugin. 

package me.hazel.myplugin;

import org.bukkit.plugin.java.JavaPlugin;

public class MyPlugin extends JavaPlugin {

    @Override
    public void onEnable() {
        getLogger().info("MyPlugin enabled!");
    }

    @Override
    public void onDisable() {
        getLogger().info("MyPlugin disabled!");
    }
}

plugin.yml 

name: MyPlugin
version: 1.0.0
main: me.hazel.myplugin.MyPlugin
api-version: '1.21'

Good practices

  • Keep your code modular.
  • Avoid unnecessary repeating tasks.
  • Validate player input.
  • Use configuration files for customizable values.
  • Avoid heavy operations on the main thread.

Commands

Creating commands for Minecraft plugins.

Example command 

public class HelloCommand
        implements CommandExecutor {

    @Override
    public boolean onCommand(
        CommandSender sender,
        Command command,
        String label,
        String[] args
    ) {

        sender.sendMessage(
            "§dHello from Hazel!"
        );

        return true;
    }
}

commands:

Development

Configuration

Using YAML configuration files to make Minecraft plugins customizable.

Example config.yml 

messages:
  welcome: "&dWelcome to the server!"
  goodbye: "&7See you next time!"

settings:
  enabled: true
  max-players: 100

database:
  host: localhost
  port: 3306
  name: minecraft

Why use configuration?

  • Server owners can customize your plugin.
  • Messages do not need to be hard-coded.
  • Settings can be changed without recompiling.
  • Plugins become easier to maintain.

Server Performance

Practical approaches to keeping Minecraft servers responsive and efficient.

Common problems

  • Too many entities.
  • Expensive repeating tasks.
  • Large synchronous database queries.
  • Poorly optimized plugins.
  • Excessive chunk loading.

Plugin development

Avoid doing expensive calculations every tick. If something does not need to happen every tick, use a longer interval. 

Bukkit.getScheduler().runTaskTimer(
    plugin,
    task,
    20L,
    20L * 5
);

Rule of thumb

Profile first, optimize second. Find the actual bottleneck before making complicated optimizations.
